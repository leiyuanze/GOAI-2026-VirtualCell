# 虚拟酵母扰动响应预测 · GOAI 2026 赛道三（虚拟细胞方向）

> 小样本、高维、强外推条件下的蛋白质组扰动响应预测：从残差分解到实体外推

## 一句话概述

面向"给定菌株/化合物/培养基/温度/时间与测量上下文，预测完整 log2 蛋白质组响应"任务，以**残差分解 + 上下文先验**为骨架，历经 v2.x（四分支残差分解）→ v3.x（结构/序列/功能先验）→ v5.x（泄漏审计 + control/delta 重构 + 菌株遗传特征）三阶段演进，最终以 **0.75×v3.7 + 0.25×v5.2 集成**作为统一评估对象。**验证集四场景蛋白 R² 中位数 0.690~0.870（5 个随机种子均值±std，std≤0.004），测试集真值自评按官方六模块加权 0.6297（修正 DEP 口径，全链路 train-only，可复现）**。初赛方案文档见 `初赛方案文档.docx`（按官方模板五章：项目概述/科学问题理解/技术方案与预期方法路线/阶段性实验/复现与开放计划）。

## 1. 任务与数据

### 1.1 科学问题

AI 虚拟细胞（AI Virtual Cell）的目标：给定条件组合预测细胞蛋白质组的整体重塑（5243 个蛋白丰度向量）。核心挑战是**小样本、高维、零样本外推**——训练约 5900 样本、输出 4422 维（过滤后），测试含未见化合物（S1）、未见菌株（S2）、双重未知（S3）与时间外推四类场景。

### 1.2 数据

| 项 | 值 |
|---|---|
| 训练样本 | 5,920（处理 5,078 / 对照 751 / 质控 91） |
| 测试样本 | 4,454（处理 4,226 / 对照 202 / 质控 26） |
| 蛋白维度 | 5,243 → 过滤缺失率<80% 后 4,422 |
| 菌株 / 化合物 | 6 菌株（train 4 + val BAI）/ 56 扰动（含对照） |
| 条件 | 2 培养基 × 2 温度（30/37℃）× 6 时间点（15~240min）× 2 质谱平台 |

### 1.3 评测（官方六模块）

匹配对照原始 FC 25%（PCC of Δ）/ 绝对保真度 20%（逐样本+逐蛋白 R²）/ 上下文均值残差 20%（新化合物）/ 药物均值残差 20%（新菌株）/ 双重未知与时间外推 10% / 高效应蛋白 DEP 检出 5%。**65% 权重围绕 Δ = 处理 − 对照**，四类 OOD 场景分别评测。复现与合规为晋级门槛（审查统计量口径、随机种子、外部数据使用与泄漏风险）。

## 2. 方法演进（做了什么、为什么、结果如何）

### 阶段一 v2.x：残差分解（把任务拆开）

- **做法**：MLP 主干 + B/S/C/T 四分支残差分解（基线/共享应激/化合物特异/菌株调制）+ 可见性门控 + 对照监督（751 对照样本）+ LOO 组件监督（μ_ctx/μ_drug 留一残差）；v2.9 加入菌株×化合物交互项。
- **动机**：评测大量基于 Δ，直接回归绝对丰度会掩盖扰动信号；四分支让架构携带对评测目标的归纳偏置。
- **结果**：val 四场景蛋白 R² 中位数约 0.66~0.88；3×v2.1 集成最优。

### 阶段二 v3.x：外部结构化先验

- **做法**：引入 Morgan 指纹、ESM2 蛋白序列先验、STRING 蛋白互作、UniProt GO 通路注意力（92 个高频通路，同一通路蛋白共享响应偏置）。
- **动机**：化合物/菌株 ID 嵌入无法外推，需要可迁移的结构与功能特征；v3.7 的 GO 通路注意力是**最强单模型**（unseen 菌株 +0.013）。
- **负向记录**：大模型（v3.8）过拟合、Dropout 反而降低效果、原始 SNP/CNV 直接接入无效。

### 阶段三 v5.x：泄漏审计与重构

1. **P0 泄漏审计（`_audit_leak.py`）**：发现并修复 3 处统计量越界——chem_emb_init 曾用 val 真值（6 个 val-only 化合物的初始特征直接编码了其真实平均响应）、matched control 曾跨划分（12 个训练样本对照来自 val）、迁移池曾含 val 对照。全部改为 **train-only**。
2. **control/delta 低秩分离（v5.0）**：按评审路线将模型拆为"状态模型（预测匹配对照）+ 扰动模型（低秩 U@z_delta）"，U 由训练集 Δ SVD 学习（方差解释约 48%）。**实证：分离单模型不如 v37 共享编码直接回归**（有意义的负面结论），但作为集成成分有互补价值。
3. **组件级监督 + RDKit 描述符（v5.1）**：补 LOO μ_ctx/μ_drug 残差监督 + 10 项 RDKit 结构描述符 → 单模型 strain +0.089 / both +0.094。
4. **菌株 SNP 遗传特征（v5.2）**：1011 酵母菌株 SNP 距离矩阵 → 菌株到训练菌株的遗传距离向量。**关键生物学信号：test 新菌株 CRD 与训练菌株 CGD 遗传距离仅 0.383**——遗传近的菌株响应可迁移。单模型 strain +0.038 / both +0.031。
5. **可靠性门控（v5.3）**：按评审建议将 seen/unseen 硬门控改为"相似度/支持数"驱动的连续门控 → **负面：无提升**（与 v4.9 结论一致，门控非瓶颈），如实记录。
6. **训练配置修正（v5.4）**：weight_decay 1e-4、阶段 C 分组学习率、残差头 L2 正则 → 持平（0.834/0.613/0.704/0.780）。
7. **θ 参数化门控 + L_rank 方向损失（v5.6）**：g_c=σ(θ0+θ1·seen+θ2·sim+θ3·log1p(n)) 可学习门控 + BCE 方向损失 → 持平（0.832/0.617/0.705/0.781），门控与排序非瓶颈再确认。
8. **对照回退 + quality 加权 + 交互编码（v5.7）**：对照匹配 5 级回退（覆盖 79%→100%，质量均值 0.836）+ control_quality 样本加权 + 菌株×化合物/上下文交互编码 → 持平（0.832/0.616/0.705/0.769），数据利用率与架构完整性提升。
9. **Morgan+desc 拼接 PCA-32（v5.8）**：2048 指纹 + 10 描述符 → PCA(32, whiten)（方差 96.3%）替换独立 morgan64+desc → 持平（0.833/0.614/0.704/0.773）。
10. **episodic training 初探**：leave-entity-out 训练目标直接对应 S1/S2/S3 → 初版未见提升（列 P1 后续方向）。

### 统一方法 vs 竞赛提交策略

- **统一方法**（科学层面）：v3.7（GO 通路注意力直接回归）与 v5.2（control/delta 分离）是两种建模路线；5 个种子下 **0.75×v3.7 + 0.25×v5.2 集成**表现最稳（std≤0.004），作为统一评估对象。
- **竞赛提交**（务实层面）：为在四类场景各自取得更稳健成绩，提交文件按场景选择不同模型组合并叠加化学结构迁移融合。**该"场景自适应"策略属竞赛选择而非可复现的科学方法本身，特此如实区分**（评审意见也指出这类策略存在"测试集适配"风险，故提交全程统计量/监督/迁移池保持 train-only）。

## 3. 结果

### 3.1 验证集（5 个随机种子 mean±std）

| 场景 | v5.2 单模型 R² | v5.2 FC PCC | 集成 R² | 集成 FC PCC |
|---|---|---:|---:|---:|
| val_chem_only（S1 新化合物） | 0.829±0.004 | 0.338±0.007 | **0.869±0.000** | 0.426±0.001 |
| val_strain_only（S2 新菌株） | 0.581±0.040 | 0.280±0.014 | **0.690±0.002** | 0.355±0.004 |
| val_both（S3 双重未知） | 0.669±0.034 | 0.223±0.010 | **0.762±0.001** | 0.234±0.003 |

**加权总分 = 0.6297**（四场景权重 1/1/0.5/0.5，近似官方组合）。M6 DEP 采用"方向准确率 40% + 高效应 PCC 30% + F1@K（50/100/200 三档均值）30%"，固定 top-K 以符合官方"避免全报阳性刷高召回"的要求。

### 3.3 负面结论汇总（方法边界）

- 门控形式（硬/连续/θ 参数化）非瓶颈（v4.9/v5.3/v5.6 一致）；排序方向损失无效（v4.3/v4.7/v5.6）；大模型过拟合（v3.8）；Dropout 降低效果；原始 SNP/CNV 直接接入无效；exp(τ) 迁移权重不如 max 加权；低秩 d=32 与 d=64 持平；episodic 初版未见提升。

### 3.4 评审共识改进（8/16 晚，全部已验证）

- **分布偏移审计**（`_audit_distribution.py`）：测试新化合物中位相似度 0.528 **高于**验证集 0.327（推翻"测试更远"假设）；测试菌株 CRD 遗传距离 0.383 近于验证菌株 BAI（1.384）；但 **平台/仪器分布明显偏移**（val_chem data_source 占比 0.270 vs test_chem 0.496）——验证/测试差异主因是测量平台分布与 Δ 精度（M1-M6 口径），而非化学/遗传外推难度
- **每蛋白收缩融合**（`_pp_weights.py` + `07n --pp`）：v5.2 在多数蛋白上 PCC 更高（w_j 均值 0.508），但 test 自评仅 +0.0004（val 上的逐蛋白优势在 test 上不成立，印证分布偏移）
- **化学迁移 2.0**（`08c`）：迁移"特异响应 Δ−μ_context" + α=0.4·clip((S_max−0.35)/0.65) 门槛，test +0.0003
- 组合（κ=100 + 迁移 2.0）：**0.6297**，替代存在复现性问题的旧提交 v52ens（0.6257）

### 3.5 科学层面验证

- 预测 Δ 显著富集到 4 个已知生物学通路（GO 富集，FDR<0.05）；
- 菌株遗传距离与响应相似度正相关，支持"遗传近 → 响应可迁移"；
- 负面结论（门控非瓶颈、exp(τ) 不如 max 加权、d=32 与 d=64 持平、episodic 初版未见提升）在初赛文档 4.1 节如实记录，界定方法边界。

## 4. 复现与合规

```bash
# 特征构建（全部 train-only 统计量）
python code/02_features.py ...    # 基础特征 + ctx_prior + matched control（train-only）
python code/_features_desc.py     # RDKit 10 项描述符
python code/_strain_genome_feats.py  # 菌株 SNP 遗传距离
python code/_features_fp32.py        # Morgan2048+desc PCA-32（结构特征联合表示）
python code/_fix_test_morgan.py   # 未见化合物 SMILES → Morgan 指纹（PubChem 下载）

# 训练（固定种子；v2.1: 42/43/44，v3.5/v3.7: 42，v5.2: 1/2/42/43/44）
python code/05b_train_v21.py 42
python code/05_train_v35.py 42
python code/05_train_v37.py 42
python code/05_train_v50.py 42     # v5.2（hard 门控, d=64）

# 评估（5-seed mean±std）
python code/_pseudo_test.py

# 提交文件生成
python code/07n_submit_v50ens.py            # 场景映射 + 集成
python code/08c_mig_fusion_adaptive.py      # 自适应 α 化学迁移融合
# 输出：data/prediction_final_0816.csv（复制到 submission_file/）

# 测试自评（官方允许"可自评不可训练"）
```

- **环境**：Python 3.9 / PyTorch（CUDA）/ scikit-learn / RDKit / pandas / numpy；单卡 GPU。
- **合规自检**：对照匹配、分组均值、SVD、迁移池全部 train-only；未见化合物指纹由 SMILES 生成；测试真值仅用于最终自评。
- **外部资源披露**：UniProt GO 注释、ESM2 嵌入、STRING PPI（v11.5）、1011 酵母 SNP 距离矩阵（Bergström et al. 2014）、PubChem SMILES；许可证与版本在初赛文档 5.3 节披露。
