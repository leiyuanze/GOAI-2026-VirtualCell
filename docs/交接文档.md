## 3. 评测结构（决定一切设计）

- 六模块：原始 FC 25%（PCC(Δ_pred,Δ_true)，Δ 服务器用真实对照算）+ 绝对保真度 20% + 上下文残差 20% + 药物残差 20% + 双重未知/时间 10% + DEP 5%
- **关键数学**：65% 分数围绕 Δ=ŷ−y_control；模块 3/4 的 μ_ctx/μ_drug 是真值常数（模型对共享响应的预测不影响模块 3/4）；PCC 对仿射不变（绝对校准不敏感、形状敏感）
- 归一化：跨方向按「相对基线」归一化 → **KPI 是相对 Matched Control 的提升幅度**，不是绝对分
- 门槛：复现与合规一票否决（统计量仅训练行、不读 test 真值、随机种子）

## 4. 模型架构与权重

**v2.1（主力，`04_model_v21.py`）**：MLP 主干（98→256→256→64）+ 残差分解 B/S/C/T 四分支（**均吃混合 latent，伪解耦**）+ 可见性门控（0.2+0.8×seen）+ 蛋白模块多头（K=64，与单层 Linear 等价）+ 批次校准分支 + SVD 先验初始化 embedding + hash。权重：`model_v21.pt`（seed42）/ `model_v21_s43.pt` / `model_v21_s44.pt`

**v2.5（`04_model_v25.py`）**：输入级分离残差分解（C 只吃化合物侧 78 维、T 只吃菌株侧 26 维）——收敛快、val_chem/val_time 强，但新菌株场景弱。权重：`model_v25_best.pt`

**最优 = 混合集成**（`07b_ensemble4.py`）：4 模型平均预测。

| 版本 | 改动 | 结果 | 结论 |
|---|---|---|---|
| v2.0 | 基础残差分解+MSE+FCcorr | val_both 0.65 | 起点 |

2. 共表达谱聚类（02 里）**相关矩阵未 mask-aware（99.6% 假 0）**——模块分组是噪声，已从创新点降级
3. 版本管理：模型文件必须版本化（`04_model_vXX.py`），勿覆盖
4. 训练 sanity check：loss 降到合理水平才可信（v2.3 的 loss 卡 0.74 就是数据错位的信号）

## 6. 为什么提升幅度小（封闭榜天花板——接手方必读）

**Matched Control 强的原因**：大部分蛋白在处理下变化不大，control 预测≈真值，逐蛋白 R² 被「不变蛋白」抬高到 0.72-0.84。

**封闭榜的信息论边界**：新化合物无结构信息、新菌株无基因组信息 → 模型对「新实体的特异响应」只能输出共享响应+平均效应。评测模块 3/4（40%）测的恰是「化合物特异/菌株调制」残差 → **封闭榜下这些指标天花板低是设计使然**（教程也承认：双重未知不强制残差、开放榜才能用外部知识）。我们能拿到的已拿到：绝对水平/共享响应/时间插值/FC 方向。

**建议的方向判断**（不是穷途）：
- 若想突破天花板 → **转开放知识榜**（基因组 k-mer/DNABERT-2 + SMILES/Morgan FP + GO/STRING 蛋白先验，全部教程 5.3 已给路径），残差分解骨架 100% 复用
- 若留封闭榜 → 提升空间在「已见菌株场景的 Δ 精度 + 组件监督强化」，边际有限；重点转向科学意义（30%）与文档质量

## 10. 新增模型版本

### v2.6（T 分支增强 + unseen 门控归零）

基于 v2.5 架构，两处改动：
- T 分支输入加入 ctx_prior 投影（4422 维蛋白空间→64 维）
- 门控从 `0.2+0.8×seen` 改为 `strain_seen×sigmoid(gate_s)`，即 unseen 菌株 T 贡献归零

结果：val_strain 0.645（+0.005 vs v2.5），但 val_both 从 0.758 降至 0.729。发现 B+S 分支也对 unseen 菌株使用了错误的 strain embedding（全部 clamp 到 strain-0）。文件：`04_model_v26.py`、`05n_train_v26.py`。

### v2.7（全 ctx_prior + unseen 均值 embedding）

在 v2.6 基础上，ctx_prior 同时喂入混合编码器（B/S 分支），且 unseen 菌株使用所有训练菌株 embedding 的均值兜底（而非 clamp 到 strain-0）。文件：`04_model_v27.py`、`05o_train_v27.py`。

结果：val_strain 0.650, val_both 0.737, val_chem 0.877。

**3×v2.1 + v2.7 集成**（`07c_ensemble5.py`，产出 `prediction_ensemble5.csv`）：val_chem 0.880, val_strain 0.664, val_both 0.758, val_time 0.829。val_both 追平 v2.1 单体最优。

### v2.8（退火 Strain + Compound Dropout）

受 TxPert（Nature Biotech 2025）leave-one-out 策略启发，训练时以退火方式随机遮蔽菌株/化合物信息（0→20%），意图模拟 unseen 场景。文件：`05p_train_v28.py`。

结果：随 dropout 增加到 20%，val_strain 从 0.650 跌至 0.506。结论：封闭榜下无基因组特征作为替代，强行"忘记"菌株只会学歪。该实验从反面验证了外部表征对泛化的必要性。

### v2.9（菌株×化合物交互项 + 自适应 loss）

在 v2.7 基础上增加两项升级：
- 交互项：`interact_mlp(hc × ht, hc, ht)`，仅在菌株和化合物均可见时激活（对应 M5 双盲场景）
- 自适应 loss 权重：Kendall 多任务不确定性，4 个 loss 各学 log-σ 自动平衡

文件：`04_model_v29.py`、`05q_train_v29.py`。

结果：val_strain 0.671（+0.021 vs v2.7）, val_both 0.757（+0.018 vs v2.7）。

**3×v2.1 + v2.9 集成**（`07e_submit_v29.py`，产出 `prediction_ensemble6.csv`）：val_chem 0.879, val_strain 0.667, val_both 0.760, val_time 0.832。**最终提交版本。**

## 18. 外部数据系统性探索（含事后归因修正，8/15 更新）

> ⚠️ **重要修正**：本节最初把多数外部数据标记为"无效"，其中部分结论被 8/15 的化学迁移融合实验推翻。下方表格区分【方法失败】与【数据无效】——凡标注"方法失败"的，是**利用方式**未对齐条件/未加权聚合所致，不是数据本身无信息，后续用正确用法可复现收益。

| 外部数据 | 用法 | 结论（含归因） |
|---|---|---|
| Morgan 指纹（PubChem+RDKit） | 2048 位 Tanimoto 单近邻/全加权迁移 | 【方法失败→已推翻】：val 集未条件对齐、2048 稀疏空间、单近邻裸迁移，收益≈0。改用 **PCA-64 + 同菌株条件对齐 + top-k 加权**（8/15），test 迁移 PCC 平均 0.127（Doxycycline 0.224/Abietic 0.258），融合提升 +0.007 |
| ESM2 蛋白序列（320维） | 输出层低秩通路 | 【方法局限】：最终模型 gate_esm≈0.28（保留约 1/4 贡献，非"关闭"）。ESM2 经 320→64 PCA 压缩且仅低秩接入，此结果只说明该接入方式增益有限，不能外推为序列信息无效 |
| 菌株 SNP 距离（1011项目） | 遗传相似度迁移 | 【证据有限】：CRD-CGD 距离 0.398 近亲但迁移收益 -0.002。验证依赖手工近似距离矩阵（DHY210 以 S288C 代理、距离设 2.3），且用"菌株平均蛋白组"混淆了背景基线 vs 扰动调制。结论应视为"未观察到有效信号"而非"确证无效" |
| 菌株拷贝数（1011项目） | 拷贝数相似度迁移 | 【证据有限】：5 菌株拷贝数几乎相同（相似度>0.91），无区分度可迁移。样本量不足以断言拷贝数变异无用 |
| 大模型+完整ESM2(320) | hidden384/latent128/5-8M参数 | 【过拟合】：val_both 0.748 退步，小样本下大模型过拟合 |
| PPI 图正则（STRING） | 约束绝对丰度接近 | 【实现错误】：v3.9 用 0.05 权重 20000 边约束绝对丰度，崩；v4.2 改 Δ 协同 (Δi−Δj)² 仍无效（强制相等是错误先验）。PPI 正确用法（相关性约束/图卷积）未验证 |

**修正后的核心结论**：评测 65% 权重在"特异效应"（M1/M3/M4），需要"功能层面"的实体差异。结构/序列/遗传表征（Morgan/ESM2/SNP/拷贝数）在**简单接入**时未见增益，但其中至少 Morgan 已被证明是**方法问题而非数据问题**——条件对齐 + 加权聚合后可迁移。小样本（43 化合物、6 菌株）下外部知识能否带来增益，取决于两点：表征是否携带功能层面的实体差异，以及利用方式是否做了条件对齐与加权聚合。
